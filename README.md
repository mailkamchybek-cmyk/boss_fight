# Boss Fight

Браузерде иштеген оюн. Баштоо үчүн `index.html` файлын ачыңыз.

## Эмне кошулду

- Оюндун HTML, CSS жана JavaScript файлдары.
- Каармандын сүрөтү жана төрт багытта басуу анимациясы.
- 50×50 клеткалуу карта жана каарманды ээрчиген камера.
- Төрт моб, чабуулдар, HP тилкелери жана зыяндын көрсөтүлүшү.
- Жеңиш/жеңилүү терезеси жана кайра ойноо баскычы.

## Башкаруу

WASD же жебелер — басуу; Space — чабуул; R — кайра баштоо.

## Чычкан менен башкаруу

Чычкандын оң баскычы — тандалган жерге баруу. Кармап жылдырсаңыз, каарман чычканды ээрчийт. Жашыл тегерек бара турган жерди көрсөтөт. WASD/жебелер басылса, чычкан берген буйрук токтойт. Space — чабуул, R — кайра баштоо.
